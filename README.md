# Мокка-Мокка — сайт кофейни

Одностраничный сайт (лендинг) кофейни «Мокка-Мокка» в г. Бузулуке.
Учебный проект: сайт сделан по бизнес-плану кофейни.

**Адрес кофейни:** г. Бузулук, ул. Комсомольская, 106Б · **Часы работы:** ежедневно 7:00–23:00

> Номер телефона и ссылки на соцсети на сайте — демонстрационные.

## Что умеет сайт

- **Меню с ценами** из бизнес-плана: кофе, завтраки, комплексный обед, напитки — во вкладках с анимацией.
- **Заказ кофе с собой** по телефону: на смартфоне кнопка сразу открывает набор номера.
- **«Сейчас открыто / закрыто»** — статус по местному времени Бузулука (UTC+5).
- **Карта Яндекса**, кнопки «Построить маршрут» и «Открыть в 2ГИС».
- **Акции:** скидка студентам, программа лояльности «Мокка-карта», абонементы для офисов.
- **Адаптивность:** удобно на телефоне, планшете и компьютере.

## Технологии

Только стандартные технологии браузера — без фреймворков и библиотек:

| Файл | Что внутри |
|---|---|
| `index.html` | Содержимое страницы, семантическая разметка (`header`, `nav`, `main`, `section`, `footer`) |
| `css/style.css` | Оформление: переменные цветов, Flexbox и Grid, подход mobile-first, медиа-запросы |
| `js/script.js` | Мобильное меню, вкладки меню, статус «открыто/закрыто», загрузка карты по мере прокрутки |
| `images/` | Логотип в нескольких размерах и иконки сайта |

Шрифт [Nunito](https://fonts.google.com/specimen/Nunito) хранится в проекте (`fonts/`, лицензия SIL OFL 1.1 — `fonts/OFL.txt`).
Единственный внешний ресурс — виджет Яндекс Карт.

## Как открыть

**Просто посмотреть:** открыть файл `index.html` двойным щелчком.

**Онлайн:** сайт опубликован на GitHub Pages (ссылка — в описании репозитория).

## Принципы, которые соблюдены

- **Mobile-first.** Сначала стили для телефона, затем расширение для планшета (от 768px) и компьютера (от 1024px).
- **Прогрессивное улучшение.** Если JavaScript не загрузится, сайт остаётся рабочим: меню навигации видно, все категории меню показаны, карта загружается обычным способом.
- **Доступность.** Смысловые теги, описания картинок (`alt`), ARIA-атрибуты у кнопки меню и вкладок, управление вкладками с клавиатуры (стрелки, Home, End), контраст текста по стандарту WCAG AA, кнопки не меньше 44×44px. Анимации отключаются, если в системе выбран режим «уменьшить движение».
- **Безопасность и приватность.** Политика безопасности контента (CSP): браузер выполняет только скрипты сайта, фреймы разрешены только для карты Яндекса. Шрифт хранится локально, поэтому данные посетителей не передаются Google. Нет форм и не собираются данные. Документы (`*.pdf`, `*.docx`) исключены из репозитория через `.gitignore`.
- **Скорость.** Свои файлы сайта весят ~180 КБ. Логотип загружается в подходящем размере (`srcset`). Карта (~2,6 МБ) загружается только когда посетитель долистал до контактов.
